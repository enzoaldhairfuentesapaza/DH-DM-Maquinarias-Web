# DH-DM-Maquinarias-Web
Plataforma web full-stack para DH &amp; DM Maquinarias SAC, empresa especializada en la venta de maquinaria pesada y repuestos. Construida con React + TypeScript + Vite en el frontend, y PHP puro (sin frameworks) con MySQL en el backend, pensada para desplegarse en hosting compartido
